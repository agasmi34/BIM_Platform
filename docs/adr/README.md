# docs/adr/

> **This directory does not hold Architecture Decision Records.** Per
> Master Engineering Constitution v0.2 and "P0-T001 Architecture Record
> Placement Correction" (Architecture Authority), the authoritative
> location for ADRs is `docs/architecture/adr/`. This directory
> (`docs/adr/`) is kept only because the P0-T001 Implementation Brief's
> canonical scaffold tree requires it to exist; it is intentionally empty
> of ADR content. Look in `docs/architecture/adr/` for actual records,
> starting with `docs/architecture/adr/ADR-0001-phase0-test-framework-baseline.md`.

Architecture Decision Records for `bim-platform` are filed under
`docs/architecture/adr/`. Any future change to a `AG-*` locked decision from
`BIM-AG-P0-T001`, or any Implementation Engineer escalation resolved as an
architectural change, is recorded there, not silently absorbed into code,
and not placed in this directory.

See `docs/tasks/P0-T001_Implementation_Brief_Claude_v1.0.md` section 2.3 for
the Architecture Clarification Request (ACR) process and section 2.2 for the
list of changes that require an ACR/ADR rather than a local implementation
decision.
